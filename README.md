\# Waymo Autonomous Vehicle Perception Dashboard



Computer Vision Analytics project using the Waymo Open Dataset.



\## Project Overview



This project analyzes autonomous vehicle perception data using Python, Pandas, and Power BI.



The workflow includes:

\- Processing parquet datasets

\- Cleaning and transforming detection data

\- Feature engineering

\- Building interactive dashboards

\- Analyzing object detection metrics



\## Technologies Used



\- Python

\- Pandas

\- Power BI

\- Parquet

\- Waymo Open Dataset



\## Dashboard Features



\- Object type distribution

\- Detection volume analysis

\- Camera detection comparison

\- Bounding box dimension analysis

\- Detection difficulty metrics

\- Interactive filtering



\## Dataset



Waymo Open Dataset:

https://waymo.com/open/
